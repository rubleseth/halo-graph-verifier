# Wayfinder

[Open the Halo graph verifier decision map](https://github.com/rubleseth/halo-graph-verifier/issues/1) for the current questions, dependencies and recorded decisions.

The December 10 competition goal is to evaluate single-call adaptive Gemma on permitted RDG exports. Testing the frozen checkpoint on a second crawler is a stretch goal. Model integration belongs in a future independent fork. The original RDG repository, services and graph are read-only to this project.

The [D08 evidence and verdict contract](https://github.com/rubleseth/halo-graph-verifier/issues/2) defines what the verifier can see and what a reviewer can conclude. The [Gemma protocol investigation](https://github.com/rubleseth/halo-graph-verifier/issues/3) investigates model and serving feasibility. The map links the remaining decisions.
